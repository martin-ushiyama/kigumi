# Security policy

## Supported version

Security fixes are applied to the latest version on the `main` branch. The hosted editor is deployed from that branch, so no older release line is maintained separately.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability.

Use **Security → Report a vulnerability** in this repository. Include the affected area, reproduction steps, impact, and any suggested mitigation. Reports will be acknowledged as soon as practical, investigated privately, and disclosed publicly after a fix is available when disclosure is appropriate.

For ordinary bugs that do not have a security impact, use the public bug-report template instead.

## Scope

Useful reports include vulnerabilities in the hosted editor, project-file parsing, `.mcpack` export, texture-pack import, and the build or deployment pipeline. Security issues in Minecraft, browser engines, GitHub, or other upstream services should be reported to their respective maintainers.
